## Activation steps (staging)
1. Create a new Supabase project; enable Email OTP/magic links, confirm email policies, configure Site URL https://tradoanson.github.io/farm-world/ and redirect allowlist for that exact URL. Disable unrestricted public signups if not intended.
2. Review and manually run db/migrations/0002_v07_supabase_rls.sql on NEW staging only. It adds public.player_farms(owner_id unique) with RLS SELECT auth.uid() and NO browser writes. Never run production migrations without approval.
3. Set GitHub Actions repository Variables NEXT_PUBLIC_SUPABASE_URL and NEXT_PUBLIC_SUPABASE_ANON_KEY (publishable anon key ONLY; never service_role). Update Pages workflow to expose those variables at build time. These values are intentionally absent in the repository.
4. A trusted server/admin must provision player_farms rows for authenticated users. There is NO browser INSERT policy. Never copy local coins/XP into cloud without server validation.
5. Test A and B accounts: each can read only own farm id, cannot read another farm, cannot insert/update/delete farm. Test logout, expired session, email redirects, iOS Safari and Android Chrome.
6. Server-authoritative gameplay commands, migration/import approval, sync and transaction tests are NOT active. Keep offline saves V1 and progression V2 unchanged.
